# Cursor Tip Calculator

A tiny, dependency-free tip calculator built as a single `index.html` file with inline CSS and a few lines of vanilla JavaScript.

- What it does: lets you enter a bill amount, choose a tip (preset buttons or custom %), set number of people, and see the tip, total, and per‑person amount update live. Includes basic input validation (no negative or NaN values) and a dark mode toggle.
- How to use: open `index.html` directly in your browser — no build step, server, or install required.
- Built with Cursor for MLH Global Hack Week: Builders Week 2026 (Cursor Challenge 1: Build a Mini App with Cursor).

## Quick start

Just double‑click `index.html` (or drag it into a browser tab).

Optional: If you want to serve it locally for testing, you can use any simple static server (e.g., `python3 -m http.server`), then visit `http://localhost:8000/cursor-tip-calculator/`.

## Features

- Bill amount input
- Tip percent via preset buttons + custom input
- Number of people input
- Live‑updating tip, total, and per‑person amounts
- Input validation for negative/invalid values
- Dark mode toggle (persists your preference)

## Files

- `index.html` — all HTML, CSS, and JS inline in one file
