The Veto Agent

An AI-agent stand-in that reads Google Calendar through Auth0 Token Vault, and pauses high-impact actions until you approve or veto them out-of-band with CIBA (Client-Initiated Backchannel Authentication).

Deterministic local responder — no LLM Mode: … Tenant: … Connection: …

How this meets the challenge

  • Token Vault exchanges an Auth0 refresh token for a Google access token before any calendar call.
  • CIBA sends an out-of-band approval for CEO meetings and unread-mail deletion. The tool does not run until you approve it.
  • A veto returns access_denied and the side effect is skipped.
Waiting for your decision

Approve or veto this request in the Auth0 Guardian app (or CIBA email) on your enrolled device.
